## Exercícios e Desafios em C

📌 **Descrição**

Repositório com exercícios e desafios práticos feitos em C. Projeto educacional com progressão de dificuldade, cobrindo desde conceitos básicos até operações mais avançadas.

🧠 **Conteúdo**

- **Módulo 00** - Introdução e primeiros passos
  - Olá Mundo
  - Entrada e saída básica
  
- **Módulo 01** - Elementos fundamentais
  - Tipos primitivos
  - Variáveis e constantes
  - Entrada de dados
  - Números aleatórios
  - Saída formatada
  
- **Módulo 02** - Operadores
  - Operadores aritméticos
  - Operadores relacionais
  - Operadores lógicos
  - Operadores de atribuição
  - Incremento e decremento
  - Operadores bit a bit
  - Operadores de deslocamento
  - Coerção de tipos
  
- **Módulo 03** - Estruturas Condicionais
  - Condição simples
  - Condições compostas
  - Condições aninhadas
  - Condições múltiplas
  - Data e hora

▶️ **Como rodar**

### Pré-requisitos
- GCC (GNU C Compiler) instalado
- Terminal/Prompt de comando

### Executar um arquivo

```bash
gcc arquivo.c -o arquivo
./arquivo
```

Ou, no Windows:
```bash
gcc arquivo.c -o arquivo.exe
arquivo.exe
```

### Compilar com flags de debug
```bash
gcc -g arquivo.c -o arquivo
```

💡 **Dicas**

- Comece pelos módulos em ordem progressiva
- Estude os exercícios antes de tentar os desafios
- Compile e teste regularmente seu código
- Use `-Wall` para ativar avisos durante compilação: `gcc -Wall arquivo.c -o arquivo`
