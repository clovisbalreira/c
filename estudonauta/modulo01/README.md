# Módulo 01 - Variáveis e Tipos de Dados

📌 Descrição  
Este módulo explora os fundamentos das variáveis, tipos de dados primitivos, constantes e entrada/saída formatada em C.

🚀 Tecnologias  
C

🎯 Funcionalidades  
- variaveis.c: Declaração e uso de variáveis  
- tiposPrimitivos.c: Exemplos de tipos int, float, char, etc.  
- constantes.c: Uso de constantes em C  
- entradaDados.c: Leitura de dados do usuário  
- saidaFormatadas.c: Formatação de saídas com printf  
- mostrarTela.c: Exemplos de exibição na tela  
- numerosAleatorios.c: Geração de números aleatórios  
- Desafios: des000.c a des005.c com exercícios práticos  

🖥️ Demonstração  
Execute os programas para testar variáveis e tipos de dados.

▶️ Como rodar  
1. Clone o repositório  
2. Navegue até a pasta modulo01  
3. Compile com: `gcc variaveis.c -o variaveis.exe`  
4. Execute: `./variaveis.exe`  
5. Repita para os outros arquivos  

📚 Aprendizados  
- Declaração e inicialização de variáveis  
- Diferença entre tipos de dados  
- Uso de constantes  
- Entrada e saída de dados  
- Formatação de strings e números
