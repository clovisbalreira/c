# Módulo 00 - Introdução ao C

📌 Descrição  
Este módulo apresenta os conceitos básicos da linguagem C, incluindo a estrutura de um programa simples, saídas na tela e entrada de dados básicos.

🚀 Tecnologias  
C

🎯 Funcionalidades  
- olamundo.c: Programa básico "Olá Mundo"  
- olamundosystem.c: Exemplo de uso do system()  
- qualseunome.c: Entrada e saída de nome do usuário  

🖥️ Demonstração  
Execute os programas em um compilador C para ver as saídas no terminal.

📸 Imagens  
![Exemplo de saída](https://via.placeholder.com/300x200?text=Sa%C3%ADda+do+Programa)

▶️ Como rodar  
1. Clone o repositório  
2. Navegue até a pasta modulo00  
3. Compile com: `gcc olamundo.c -o olamundo.exe`  
4. Execute: `./olamundo.exe`  
5. Repita para os outros arquivos  

📚 Aprendizados  
- Estrutura básica de um programa em C  
- Uso de printf() para saída  
- Uso de scanf() para entrada  
- Comandos do sistema com system()
