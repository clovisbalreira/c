# Módulo 02 - Operadores

📌 Descrição  
Este módulo cobre os operadores aritméticos, de atribuição, relacionais, lógicos, bit a bit e outros operadores em C.

🚀 Tecnologias  
C

🎯 Funcionalidades  
- aritimeticos.c: Operadores aritméticos (+, -, *, /, %)  
- atribuicao.c: Operadores de atribuição (=, +=, etc.)  
- operadoresRelacionais.c: Comparações (==, !=, <, >, etc.)  
- operatresLogico.c: Operadores lógicos (&&, ||, !)  
- ternario.c: Operador ternário (? :)  
- bitBit.c: Operadores bit a bit (&, |, ^, ~, <<, >>)  
- operadoresDeslocamento.c: Deslocamento de bits  
- incrementoDecremento.c: ++ e --  
- coercao.c: Conversão de tipos  
- conversaoDecimalBinaria.c: Conversão decimal para binário  
- conversaoBinariaDecimal.c: Conversão binário para decimal  
- Desafios: des006.c a des014.c com exercícios  

🖥️ Demonstração  
Execute os programas para ver operações matemáticas e lógicas.

▶️ Como rodar  
1. Clone o repositório  
2. Navegue até a pasta modulo02  
3. Compile com: `gcc aritimeticos.c -o aritimeticos.exe`  
4. Execute: `./aritimeticos.exe`  
5. Repita para os outros arquivos  

📚 Aprendizados  
- Operações aritméticas básicas  
- Atribuição composta  
- Comparações e lógica booleana  
- Manipulação de bits  
- Conversões entre sistemas numéricos
