# Módulo 03 - Estruturas de Controle

📌 Descrição  
Este módulo ensina estruturas condicionais simples, compostas, aninhadas e múltiplas, além de manipulação de data e hora em C.

🚀 Tecnologias  
C

🎯 Funcionalidades  
- condicaoSimples.c: If simples  
- condicoesCompostas.c: If-else  
- condicaoAninhada.c: If aninhados  
- condicoesMultiplas.c: Switch-case  
- dataHora.c: Manipulação de data e hora  
- Desafios: des015.c a des030.c com exercícios práticos  

🖥️ Demonstração  
Execute os programas para testar tomadas de decisão.

📸 Imagens  
![Exemplo de saída](https://via.placeholder.com/300x200?text=Sa%C3%ADda+do+Programa)

▶️ Como rodar  
1. Clone o repositório  
2. Navegue até a pasta modulo03  
3. Compile com: `gcc condicaoSimples.c -o condicaoSimples.exe`  
4. Execute: `./condicaoSimples.exe`  
5. Repita para os outros arquivos  

📚 Aprendizados  
- Estruturas de decisão if-else  
- Switch para múltiplas opções  
- Aninhamento de condições  
- Manipulação de tempo e data em C
